# Визитка Студии Вокала «Твой Голос»

## Описание проекта
Профессиональная интерактивная визитка преподавателя вокала **Ирека Гайнемухаметова**. Одностраничный веб-сайт с современным дизайном, предназначенный для привлечения новых учеников и демонстрации услуг студии.

## Целевая аудитория
- Люди, заинтересованные в уроках вокала
- Те, кто ищет опытного педагога
- Потенциальные клиенты из социальных сетей и рекомендаций

## Структура страницы

### 1. Шапка (Logo Section)
- Круглый логотип с фото Ирека
- Текст по периметру: "СТУДИЯ ВОКАЛА" (сверху), "ТВОЙ ГОЛОС" (снизу)
- Имя и роли: "Ирек Гайнемухаметов · педагог · певец · ведущий"

### 2. Основное предложение
- Заголовок: "Запоёте **любимую песню**"
- Слоган: "Даже если всю жизнь думали, что это невозможно"

### 3. Ключевые преимущества
- ⭐ Первый результат на пробном уроке
- ⭐ Только индивидуально, без групп
- ⭐ 20+ лет методики для начинающих с нуля
- ⭐ Онлайн из любого города России
- ⭐ 30+ лет опыта на сцене

### 4. Отзывы клиентов
- 3 реальных отзыва в стиле скриншотов сообщений
- От Дмитрия, Анны, Марины

### 5. Кнопка на отзывы 2GIS
- Ссылка на отзывы в 2GIS
- Золотой стиль с эффектом при наведении

### 6. CTA-кнопка
- "🎤 Записаться на пробный урок"
- Ведет на форму записи в ВКонтакте
- С пульсирующим эффектом

### 7. Социальные сети
- ВКонтакте (форма записи)
- Instagram
- Telegram
- Телефон

### 8. Footer
- "Нижнекамск · онлайн по России"

## Дизайн

### Цветовая схема
- **Фон**: темный (#0a0a0a)
- **Основной акцент**: бирюзовый (#00d2c8)
- **Вторичный акцент**: золотой (#d4af37)
- **Текст**: белый и полупрозрачный белый

### Эффекты и анимации
- Мерцающие звезды на фоне (150 звезд)
- Туманность (nebula) с пульсацией
- Появление карточки при загрузке (cardAppear)
- Пульсация вокруг кнопки CTA
- Свечение и тени на элементах

### Адаптивность
- Мобильная версия с меньшими размерами
- Максимальная ширина карточки: 480px
- Респонсивные шрифты и отступы

## Технические детали

### Файлы
- **index.html** — основной файл (весь проект в одном файле)

### Зависимости
- **Нет внешних зависимостей** — только HTML, CSS, JavaScript
- Использованы встроенные шрифты системы (Segoe UI, Apple System)
- SVG для логотипа с текстом по дуге

### Изображения
- **irek-photo.jpg** — фото преподавателя в логотипе

## История версий

- Логотип с текстом на внешнем периметре
- Имя крупное (32px)
- Отзывы в стиле скриншотов

- Форма записи через ВКонтакте
- Удалены все старые версии (index-photo.html, index-v2.html, vizitka-full.html и др.)

## Как использовать

1. Открыть `index.html` в браузере
2. Всё работает offline (без интернета)
3. При клике на кнопку "Записаться" откроется форма в ВК
4. При клике на 2GIS откроется страница отзывов

## Развертывание

Можно разместить на:

- Любом веб-хостинге (просто залить `index.html`)
