# Визитка «Твой Голос» — инструкции для Claude

## Описание проекта
Интерактивная визитка преподавателя вокала Ирека Гайнемухаметова. Одностраничный сайт с современным дизайном, анимациями и активными ссылками на форму записи и отзывы.

## Структура папки
```
vizitka/
├── index.html          # Основной файл (весь сайт в одном файле)
├── irek-photo.jpg      # Фото преподавателя
├── I4ovOZ.png          # Изображение для социальных сетей
├── irek-profile.png    # Профиль фото
├── PROJEKT.md          # Описание проекта
├── PLAN.md             # План развития
└── CLAUDE.md           # Этот файл
```

## Основные элементы

### 1. Логотип
- SVG с текстом по периметру круга
- "СТУДИЯ ВОКАЛА" сверху (белый)
- "ТВОЙ ГОЛОС" снизу (бирюзовый, читается слева направо)
- Фото в центре (object-position: center 5%)

### 2. Основная информация
- Имя: "Ирек Гайнемухаметов" (32px, bold, белый)
- Роли: "педагог · певец · ведущий" (12px, бирюзовый)

### 3. Преимущества (5 пунктов)
Все с эмодзи звездочек (⭐)

### 4. Отзывы (3 шт)
Стиль скриншотов с:
- Текстом отзыва
- Имя клиента (бирюзовое)
- Границы и тени для реалистичности

### 5. Кнопка 2GIS
После отзывов, ведет на поиск отзывов в 2GIS

### 6. CTA-кнопка
"🎤 Записаться на пробный урок" → форма ВК

## Правила редактирования

1. **НЕ менять структуру** - всё в одном файле index.html
2. **Сохранить дизайн** - темный фон, бирюзовый акцент, анимации
3. **Ссылки** - всегда обновлять если меняются контакты
4. **Фото** - название файла: irek-photo.jpg
5. **Текст отзывов** - максимум 2-3 предложения

## При изменениях

1. Открыть `index.html` в браузере для проверки
2. Проверить все ссылки (они должны открываться)
3. Проверить на мобильных экранах
4. Закоммитить изменения
5. Обновить дату в PLAN.md
