# 🎤 Студия вокала «Твой Голос» — Автономная версия

## Что это?
Полностью автономная визитка, которая работает **без интернета** на **любом устройстве**.

## Как использовать?

### На компьютере (Windows, Mac, Linux)
1. Открыть файл **index.html** в браузере (Chrome, Firefox, Safari, Edge)
2. Готово! Всё работает

### На телефоне/планшете (iOS, Android)
1. Скачать папку `vizitka-avtonomnaya/` на телефон
2. Открыть файл **index.html** в браузере (Chrome, Safari, Mozilla)
3. Готово!

### Поделиться с друзьями
- Скопировать папку `vizitka-avtonomnaya/` на USB флешку
- Отправить папку по WhatsApp, Telegram, Email
- Залить на облако (Google Drive, Яндекс.Диск, OneDrive)
